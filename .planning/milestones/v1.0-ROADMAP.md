# Project Roadmap (`999xgame-kotlin`)

## Milestone 1: Production Core Architecture & Game Foundation

- [x] **Phase 1: Persistence & Database Initialization**
  - Connect HikariCP PostgreSQL pool & execute migration DDLs.
  - Implement basic user authentication endpoints (JWT/Bcrypt).

- [x] **Phase 2: Financial Ledger & Wallet Subsystem**
  - Implement ledger-backed wallet balances (deposit, winnings, bonus, withdrawable).
  - Build Deposit and Withdrawal request, queue, approval, and audit workflows.

- [x] **Phase 3: Base Game Engines Implementation**
  - Implement provably fair RNG algorithms & engine logic for Coin Flip, Classic Dice, Keno, Mines, Perya Color Game, Ring of Fortune, Double, Limbo.
  - Implement round state machines, payout calculators, and result verifiers.

- [x] **Phase 4: Realtime Gateway & WebSockets Integration**
  - Implement Ktor WebSocket session manager for live game events, round countdowns, and balance sync.

- [x] **Phase 5: Admin Panel & Governance APIs**
  - Implement admin controllers for withdrawal processing, user management, game toggles, and audit logs.

- [x] **Phase 6: Android App Integration & End-to-End Verification**
  - Bind Jetpack Compose UI screens to live REST and WebSocket endpoints.
  - Execute end-to-end integration tests across deposit, gameplay, and withdrawal flows.
