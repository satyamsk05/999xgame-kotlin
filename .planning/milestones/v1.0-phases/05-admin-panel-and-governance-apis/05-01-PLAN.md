# Plan 05-01: Admin Panel & Governance APIs Implementation

**Phase:** 5 (Admin Panel & Governance APIs)
**Plan:** 05-01
**Mode:** tracer-first

## Goal
Build role-based admin authentication, financial approval workflows (withdrawal/deposit approval/rejection), user moderation (block/unblock), game stake limit management, and audit logging.

## User Stories & Requirements Addressed
- **US-05**: Role-based admin access, financial approvals, user management, game control, and audit logs.

## Tasks

### Task 1: Admin Module Linkage & Admin Auth Service (`AdminAuthService`)
- **Files**:
  - `backend/build.gradle.kts`
  - `admin/src/main/kotlin/com/ingames/admin/authentication/AdminAuthService.kt`
  - `admin/src/main/kotlin/com/ingames/admin/authentication/AdminRoutes.kt`
- **Action**: Add `:admin` dependency to `:backend`, build admin authentication controller (`login`, JWT verification), and role guards (`SUPER_ADMIN`, `FINANCE_ADMIN`, `GAME_ADMIN`).
- **Verification**: Unit test admin login & JWT validation.

### Task 2: Financial Approvals & Governance (`AdminFinancialService`)
- **Files**:
  - `admin/src/main/kotlin/com/ingames/admin/withdrawals/AdminWithdrawalService.kt`
  - `admin/src/main/kotlin/com/ingames/admin/deposits/AdminDepositService.kt`
- **Action**: Implement withdrawal approval (status update to `SUCCESS`, ledger audit entry) and withdrawal rejection (status update to `REJECTED`, refund reserved balance to user with audit note). Implement UTR deposit verification/rejection.
- **Verification**: Integration test asserting withdrawal approval & refund logic.

### Task 3: User Moderation, Game Config & Audit Logging (`AdminGovernanceRoutes`)
- **Files**:
  - `admin/src/main/kotlin/com/ingames/admin/users/AdminUserService.kt`
  - `admin/src/main/kotlin/com/ingames/admin/games/AdminGameConfigService.kt`
  - `admin/src/main/kotlin/com/ingames/admin/audit/AuditLogService.kt`
- **Action**: Build routes for user moderation (`/api/admin/users/{id}/block`), game stake limits (`/api/admin/games/{id}/config`), and audit logging (`/api/admin/audit-logs`).
- **Verification**: Automated test suite asserting admin endpoints and audit log creation.
