# Plan 03-01: Base Game Engines Implementation

**Phase:** 3 (Base Game Engines Implementation)
**Plan:** 03-01
**Mode:** tracer-first

## Goal
Implement provably fair algorithms, round processing, and unit tests for the 8 base game engines (Coin Flip, Classic Dice, Keno, Mines, Perya Color Game, Ring of Fortune, Double, Limbo).

## User Stories & Requirements Addressed
- **US-03**: Provably fair game outcomes for the 8 base games.

## Tasks

### Task 1: Coin Flip & Classic Dice Engines
- **Type**: tracer
- **Files**:
  - `games/src/main/kotlin/com/ingames/games/games/coinflip/CoinFlipEngine.kt`
  - `games/src/main/kotlin/com/ingames/games/games/classicdice/ClassicDiceEngine.kt`
- **Action**: Implement Provably Fair SHA-256 evaluation for Coin Flip (HEADS/TAILS) and Classic Dice (0.00-99.99 rolls).
- **Verification**: Unit tests in `games/src/test/kotlin/com/ingames/games/games/coinflip/` and `classicdice/`.

### Task 2: Keno, Mines & Perya Color Engines
- **Type**: expansion
- **Files**:
  - `games/src/main/kotlin/com/ingames/games/games/keno/KenoEngine.kt`
  - `games/src/main/kotlin/com/ingames/games/games/mines/MinesEngine.kt`
  - `games/src/main/kotlin/com/ingames/games/games/peryacolor/PeryaColorEngine.kt`
- **Action**: Implement 10-number Keno draw, 25-tile Mines grid generator, and 3-dice Perya Color roll calculation.
- **Verification**: Unit tests verifying seed determinism and payout evaluations.

### Task 3: Ring of Fortune, Double & Limbo Engines
- **Type**: expansion
- **Files**:
  - `games/src/main/kotlin/com/ingames/games/games/ringoffortune/RingOfFortuneEngine.kt`
  - `games/src/main/kotlin/com/ingames/games/games/double/DoubleGameEngine.kt`
  - `games/src/main/kotlin/com/ingames/games/games/limbo/LimboEngine.kt`
- **Action**: Implement 54-segment wheel evaluation, 15-slot Double wheel calculation, and Limbo target multiplier curve engine.
- **Verification**: Unit tests asserting multiplier outcome calculation bounds.
