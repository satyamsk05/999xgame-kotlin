# Plan 04-01: Realtime Gateway & WebSockets Integration Implementation

**Phase:** 4 (Realtime Gateway & WebSockets Integration)
**Plan:** 04-01
**Mode:** tracer-first

## Goal
Build Ktor WebSocket channels for game round broadcasts, live timers, and user balance sync.

## User Stories & Requirements Addressed
- **US-04**: Realtime WebSocket round updates, timers, and balance sync.

## Tasks

### Task 1: WebSocket Session Manager (`WebSocketManager`)
- **Type**: tracer
- **Files**:
  - `backend/src/main/kotlin/com/ingames/realtime/WebSocketManager.kt`
- **Action**: Build `WebSocketManager` supporting session registration (`joinGameChannel`, `leaveGameChannel`), channel broadcasting (`broadcastToGame`), and user targeted notifications (`sendToUser`).
- **Verification**: Unit test `WebSocketManagerTest` asserting channel registration and session message routing.

### Task 2: Ktor WebSocket Endpoints & Route Definitions
- **Type**: expansion
- **Files**:
  - `backend/src/main/kotlin/com/ingames/realtime/RealtimeRoutes.kt`
- **Action**: Implement Ktor routes `/ws/game/{gameId}` and `/ws/user/{userId}` for bidirectional live event streaming.
- **Verification**: Integration test asserting WebSocket connection and ping/pong message handling.
