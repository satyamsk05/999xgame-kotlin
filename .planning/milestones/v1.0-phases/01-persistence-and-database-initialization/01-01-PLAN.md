# Plan 01-01: Database Connection Pool & Auth API Implementation

**Phase:** 1 (Persistence & Database Initialization)
**Plan:** 01-01
**Mode:** tracer-first

## Goal
Initialize HikariCP PostgreSQL database connectivity in Ktor backend, execute SQL migration DDLs, and implement JWT/Bcrypt registration and login routes.

## User Stories & Requirements Addressed
- **US-01**: PostgreSQL DDL & HikariCP pool initialization.
- **US-05**: Auth & Role tokens setup.

## Tasks

### Task 1: HikariCP Database Connection Pool & Migration Setup
- **Type**: tracer
- **Files**:
  - `backend/src/main/kotlin/com/ingames/config/DatabaseConfig.kt`
  - `backend/src/main/kotlin/com/ingames/database/DatabaseFactory.kt`
- **Action**: Implement `DatabaseFactory` to configure HikariCP DataSource with PostgreSQL driver, pool settings, and automatic migration script runner over `database/migrations/`.
- **Verification**: Run unit test verifying `DatabaseFactory.init()` creates a valid connection.

### Task 2: JWT & Password Hashing Configuration
- **Type**: expansion
- **Files**:
  - `backend/src/main/kotlin/com/ingames/config/JwtConfig.kt`
  - `backend/src/main/kotlin/com/ingames/auth/PasswordHasher.kt`
- **Action**: Build JWT token generator/verifier using Ktor Auth JWT and password hashing helper using Bcrypt.
- **Verification**: Unit tests for password hash matching and JWT token validation.

### Task 3: Ktor Registration & Login API Routes
- **Type**: expansion
- **Files**:
  - `backend/src/main/kotlin/com/ingames/auth/AuthRoutes.kt`
  - `backend/src/main/kotlin/com/ingames/auth/AuthController.kt`
- **Action**: Build `POST /api/auth/register` and `POST /api/auth/login` endpoints accepting user credentials and returning JWT tokens.
- **Verification**: Run Ktor integration test asserting register and login HTTP 200 responses.
