# Plan 06-01: Android App Integration & End-to-End Verification Implementation

**Phase:** 6 (Android App Integration & End-to-End Verification)
**Plan:** 06-01
**Mode:** tracer-first

## Goal
Bind Android Jetpack Compose UI screens to live REST and WebSocket endpoints, implement Android `RealtimeClient`, and execute end-to-end integration tests across deposit, gameplay, admin governance, and withdrawal flows.

## User Stories & Requirements Addressed
- **US-04**: Realtime WebSocket round updates and balance sync in Android app.
- **Definition of Done**: Clean build (`./gradlew check`) and 100% test pass rate across all 5 Gradle modules.

## Tasks

### Task 1: Real-Time WebSocket Client (`RealtimeClient.kt`)
- **Files**:
  - `android/app/src/main/kotlin/com/ingames/app/data/RealtimeClient.kt`
- **Action**: Implement WebSocket connection manager subscribing to `/ws/game/{gameId}` and `/ws/user/{userId}` endpoints and updating live UI state flows.
- **Verification**: Unit test asserting message serialization and state dispatch.

### Task 2: End-to-End Integration Suite (`E2EIntegrationTest.kt`)
- **Files**:
  - `backend/src/test/kotlin/com/ingames/e2e/E2EIntegrationTest.kt`
- **Action**: Implement full integration test covering user OTP authentication, deposit request & admin UTR approval, game bet placement & outcome calculation, and withdrawal request & admin approval.
- **Verification**: Run `E2EIntegrationTest` to verify 100% end-to-end platform flow.

### Task 3: Multi-Module Project Check
- **Files**:
  - All Gradle modules (`:shared`, `:backend`, `:games`, `:admin`, `:android:app`).
- **Action**: Run `./gradlew check` and `./gradlew test` across the workspace.
- **Verification**: `BUILD SUCCESSFUL` across all 5 modules.
