# Plan 02-01: Financial Ledger & Wallet Subsystem Implementation

**Phase:** 2 (Financial Ledger & Wallet Subsystem)
**Plan:** 02-01
**Mode:** tracer-first

## Goal
Build a thread-safe multi-balance wallet ledger engine with deposit order initiation, withdrawal queue workflows, and REST API endpoints.

## User Stories & Requirements Addressed
- **US-02**: Audited ledger balance system & multi-balance transactions.
- **US-05**: Admin withdrawal approval & deposit reconciliation support.

## Tasks

### Task 1: Core Financial Ledger Engine (`FinancialService`)
- **Type**: tracer
- **Files**:
  - `backend/src/main/kotlin/com/ingames/wallet/FinancialService.kt`
- **Action**: Implement `FinancialService` with atomic `debitForBet`, `creditWinnings`, `initiateDeposit`, `submitUtr`, `requestWithdrawal`, and `getTransactions` supporting both PostgreSQL transactions and thread-safe `MemoryDataStore` fallback.
- **Verification**: Unit tests in `FinancialServiceTest` asserting balance math, order of deduction (deposit -> winnings -> bonus), and idempotency deduplication.

### Task 2: Wallet REST API Routes
- **Type**: expansion
- **Files**:
  - `backend/src/main/kotlin/com/ingames/wallet/WalletRoutes.kt`
  - `backend/src/main/kotlin/com/ingames/wallet/WalletController.kt`
- **Action**: Build Ktor route endpoints:
  - `GET /api/wallet/balance` (returns deposit, winnings, bonus, total balance)
  - `GET /api/wallet/transactions` (returns historical ledger entries)
  - `POST /api/wallet/deposit/initiate` (creates deposit order & QR Code link)
  - `POST /api/wallet/deposit/utr` (submits UTR reference number)
  - `POST /api/wallet/withdrawal/request` (submits withdrawal request & locks winnings balance)
- **Verification**: Ktor integration test verifying HTTP responses for balance and deposit endpoints.
